5. Is there anything special we need to know in order to run your code?

The project uses JavaScript, TypeScript, and Vega-Lite.

To run the project:
1. Open a terminal in the repository's root directory.
2. Compile TypeScript using:
   tsc --p tsconfig.json
3. Start a local web server using:
   live-server
4. Open index.html, activities.html, or descriptions.html.

The generated js/tweet.js file is excluded by .gitignore.
It should be generated by compiling ts/tweet.ts before
opening the webpages.

The optional bonus feature adds a Sentiment column to the
search results table on descriptions.html.

Sentiment analysis uses a dictionary-based approach:
- Positive words increase the sentiment score.
- Negative words decrease the sentiment score.
- A positive score is classified as "Positive".
- A negative score is classified as "Negative".
- A zero score is classified as "Neutral".

The sentiment analysis is performed on user-written tweet
text. It does not require machine learning models or
external sentiment analysis APIs.

The original tweet summary, activity visualizations,
interactive chart toggling, and real-time text search
features remain available.
